# IKEA Egypt – Ceiling Lights Web Scraper

## Project Overview
A Python web scraping project built with Selenium to collect ceiling light product information from IKEA Egypt.

## Website
https://www.ikea.com/eg/en/search/?q=ceiling-lights

## Technologies Used
- Python
- Selenium
- XPath
- CSV

## Data Extracted
- Product Name
- Product Description
- Price
- Availability Status
- Product Image URL
- Product URL

## Features
- Scrapes ceiling light products across multiple pages.
- Collects product names and descriptions.
- Extracts product prices and availability status.
- Retrieves product image URLs and direct product links.
- Handles missing names, descriptions, and prices.
- Exports the collected product data to a CSV file.

## Output
The extracted product data is saved in `all products.csv`.

---

**Note:** This project demonstrates practical web scraping using Python and Selenium on a real e-commerce website.
